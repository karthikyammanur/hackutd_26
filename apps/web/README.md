# Safe Signal web

React and Vite, hosted as a static-assets Cloudflare Worker.

```bash
npm run dev      # local dev server
npm run build    # typecheck, then build to dist/
npm run lint
npm test         # proxy and API parsing (needs Bun)
npm run deploy   # build, then publish with Wrangler
```

`src/contracts.ts` is generated by `checks/gen_types.sh`. Don't edit it by hand.

## Simulate

`#simulate` starts and follows real sandbox runs. `worker/proxy.ts` forwards `/sandbox-api/*` to the backend and adds the password, so it never reaches the browser. The proxy caps each run at 2,000 cases and 8 lanes.

```bash
wrangler secret put SANDBOX_PASSWORD   # same value as sandbox/worker/.env
```
